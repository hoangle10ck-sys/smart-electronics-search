# TechAPI catalog data attribution

The 30 published SoC records imported from TechAPI are attributed as **Data from TechAPI** and link to the [TechAPI repository](https://github.com/GetTechAPI/TechAPI). Each record stores its TechAPI source page, a manufacturer source URL, and its data license in MongoDB.

TechAPI's product data and static JSON API are licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). The TechAPI license requires attribution and release of derived TechAPI data under the same license. Preserve the per-record attribution and license fields when exporting or distributing these rows. This notice applies to TechAPI-derived records; other catalog records retain their own source terms.

No TechAPI image URLs or image files were imported with these SoC records.
